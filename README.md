## Описание проекта

Двумерная игра «Астероиды» на Python и pygame. Игрок управляет кораблём,
стреляет по астероидам и набирает очки. При столкновениях корабль теряет
жизни, а на месте астероида появляется анимация взрыва.

## Функциональные возможности

### Основные

- Вращение корабля, ускорение и стрельба ракетами.
- Случайное появление и вращение астероидов.
- Перенос объектов через противоположные границы поля.
- Проверка столкновений, подсчёт очков и жизней.
- Заставка, неподвижный фон и движущийся полупрозрачный фон.
- Смена изображения при тяге и покадровая анимация взрыва.

### Дополнительные

- Повторная игра после поражения.

## Требования к системе

- Python 3.10–3.12.
- Windows, macOS или Linux с графическим интерфейсом.
- pygame 2.6.1; стандартные библиотеки math и random.

## Установка и запуск

### 1. Скачать проект

```bash
git clone https://github.com/komushkin/asteroids.git
cd asteroids
```

### 2. Создать и активировать виртуальное окружение

Папка venv сохранена по требованиям работы. После скачивания пересоздайте
окружение для своего компьютера.

Windows (командная строка cmd):

```bat
python -m venv --clear venv
venv\Scripts\activate.bat
```

macOS / Linux:

```bash
python3 -m venv --clear venv
source venv/bin/activate
```

### 3. Установить зависимости

```bash
python -m pip install -r requirements.txt
```

### 4. Запустить игру

```bash
python main.py
```

### Управление

- Щелчок по прямоугольнику заставки — начать игру.
- Стрелки влево и вправо — вращать корабль.
- Стрелка вверх — включить двигатель.
- Пробел — стрелять.
- Escape или закрытие окна — выход.

## Структура проекта

```text
asteroids/
├── .gitignore
├── README.md
├── requirements.txt
├── main.py
├── settings.py
├── sprites.py
├── graphics.py
└── venv/
```

main.py запускает окно и управляет игрой; settings.py содержит параметры;
sprites.py описывает корабль, ракеты и астероиды; graphics.py создаёт
изображения, фоны и анимацию взрыва. Код разделён на четыре файла по заданию.
Изображения создаются программно, дополнительные файлы графики не нужны.

## Пример использования

Запустите main.py и щёлкните по заставке. Поверните корабль стрелками,
нажмите вверх для движения и пробел для выстрела. За каждый сбитый
астероид начисляется одно очко.

В начале доступны 3 жизни и 0 очков. По условию задания поражение наступает
при столкновении, если перед ним оставалось 0 жизней. Иначе корабль
возрождается в центре, а число жизней уменьшается на одну. После поражения
счёт остаётся на экране; щелчок по заставке начинает новую игру.
